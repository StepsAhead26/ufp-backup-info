# UFP Backup

UFP Backup is a private administrative tool operated by Steps Ahead Pvt Ltd to back up its UFP damages-module database.

The tool uses Google Drive authorization to upload encrypted backup files to a designated private folder and retrieve them for integrity checks and recovery testing.

It is intended for authorized administrators, not public registration. This website provides information only and does not provide access to the application, database or backups.

Google authorization does not make backup files public.
